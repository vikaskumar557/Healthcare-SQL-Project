# Healthcare Data Analysis Using SQL

## Project Description

Developed a Healthcare Data Analysis project using MySQL to analyze patient information, doctor details, appointments, and medical records. The project includes 26 SQL queries across Basic, Intermediate, and Advanced levels to extract meaningful insights from healthcare data.

## Key Highlights

* Retrieved and filtered patient and doctor information using `SELECT`, `WHERE`, and `DISTINCT`.
* Analyzed patient demographics, blood groups, and doctor specializations.
* Used `INNER JOIN` to combine patient, doctor, appointment, and medical record data.
* Applied aggregate functions such as `COUNT()`, `SUM()`, and `AVG()` to calculate appointment counts, consultation revenue, and average fees.
* Created SQL views to organize and simplify data analysis.
* Used `GROUP BY`, `HAVING`, and `ORDER BY` to summarize and sort healthcare data.
* Applied subqueries and window functions such as `RANK()` and `ROW_NUMBER()` for advanced analysis.
* Calculated monthly consultation revenue and running totals.
* Compared doctors' appointment counts with the average appointment count.

## Tools & Technologies

**MySQL | MySQL Workbench | SQL | Views | Joins | Aggregate Functions | Subqueries | Window Functions**

## Project Objective

To strengthen SQL skills and derive meaningful insights from healthcare data to support reporting, performance analysis, and data-driven decision-making.
